# Atlas ERP

Sistema ERP desarrollado como proyecto de graduación utilizando:

- Python
- Django
- MySQL
- Bootstrap 5
- Git
- GitHub

## Descripción

Atlas ERP es una plataforma web orientada a la gestión administrativa de Importadora Pérez, permitiendo administrar clientes, proveedores, productos, inventario, compras y pedidos, incorporando herramientas de apoyo para la toma de decisiones.
